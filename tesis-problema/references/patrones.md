# Patrones del Capítulo I

## Cuadro diagnóstico (Méndez Álvarez), para armar 1.1 antes de redactar

| Síntomas (con cifra) | Causas | Pronóstico | Control al pronóstico |
|---|---|---|---|
| Qué se observa y cuánto | Por qué ocurre | Qué pasa si no se interviene | Qué se propone (VI) |

Llénalo con la persona durante el grilling. Cada fila se convierte en un párrafo del
tramo "Sin embargo…" de la descripción.

## Niveles de pregunta (Ciro Espinoza Montes)

| Nivel | Forma |
|---|---|
| Descriptivo | ¿Cuáles son las características de X que genera Y? |
| Explicativo | ¿Por qué X permite generar Y? |
| Experimental | ¿Cómo combinar X para mejorar/reducir Y? |
| Aplicada | ¿Cómo configurar X para mejorar la eficiencia de Y? |

Para una tesis pre/post de Sistemas se recomienda la forma explicativa-aplicada con
"¿En qué medida…?", porque se responde con un indicador y una prueba estadística.

## Ejemplo coherente (tema: WhatsApp + OpenAI; ilustrativo)

- **Título**: SISTEMA WEB CON INTELIGENCIA ARTIFICIAL CONVERSACIONAL INTEGRADO A
  WHATSAPP PARA LA ATENCIÓN DE CONSULTAS DE CLIENTES EN UNA EMPRESA DE LIMA SUR
- **PG**: ¿En qué medida un sistema web con inteligencia artificial conversacional
  integrado a WhatsApp mejora la atención de consultas de clientes en la empresa X?
- **OG**: Determinar en qué medida un sistema web con inteligencia artificial
  conversacional integrado a WhatsApp mejora la atención de consultas de clientes en
  la empresa X.
- **PE1**: ¿En qué medida … reduce el tiempo promedio de primera respuesta …?
  **OE1**: Determinar en qué medida … reduce el tiempo promedio de primera respuesta …
- **PE2**: ¿En qué medida … incrementa la tasa de consultas resueltas sin intervención
  humana …? **OE2**: Determinar en qué medida … incrementa la tasa …

## Malos → buenos (errores reales del proyecto anterior y de compañeros)

| Malo | Por qué | Bueno |
|---|---|---|
| ¿Cómo implementar redes neuronales para la predicción…? | Es una actividad | ¿En qué medida el modelo X incrementa la precisión de…? |
| Implementar redes neuronales por propagación hacia atrás… (objetivo) | Actividad, no se mide | Determinar la precisión alcanzada por… |
| ¿Cuál es una de las implementaciones… con mayor eficacia…? | Ambiguo ("una de", "eficacia" sin definir) | ¿Qué configuración de … obtiene mayor F1-score en…? |
| Mejorar la atención al cliente mediante un chatbot | Verbo "mejorar" + medio en el objetivo | Determinar en qué medida el sistema … reduce el tiempo de… |
| "…es una forma increíble para procesar datos" (justificación) | Valorativo, sin cita | "…permitió reducir en 35 % el tiempo de… (Autor, 2024)" |

## Verbos

- **Recomendados** (objetivo general/específicos): determinar, evaluar, establecer,
  comprobar, verificar, analizar, describir, identificar, calcular, estimar.
- **Evitar**: mejorar, conocer, saber, capacitar, orientar, motivar, cambiar, enseñar,
  hacer, implementar/desarrollar (como objetivo de investigación).

## Plantillas de párrafo de justificación

- Teórica: "Desde el punto de vista teórico, la investigación permitirá contrastar
  … con lo reportado por \textcite{clave}, quienes …"
- Práctica: "En el plano práctico, … afronta un promedio de N consultas diarias
  \parencite{clave}; contar con … permitirá …"
- Metodológica: "Metodológicamente, se elaborará una ficha de registro validada por
  juicio de expertos que podrá ser utilizada en investigaciones similares …"
- Económica: "Considerando un costo de S/ … por …, la reducción de … representaría un
  ahorro estimado de …"
