# Design language — the "paper map + sticker" family

Every transition in this family must feel like it belongs to the same vlog.
These are the shared decisions; per-project variation lives in
`transition.config.json` (`style`), not in ad-hoc edits.

## Style pack (defaults)

| Token | Value | Used for |
| --- | --- | --- |
| `style.paper` | `#f3ead7` | map paper base |
| `style.ink` | `#4a3b2a` | labels, drawn geography linework |
| `style.route` | `#c73e3e` | route line, markers |
| `style.fontFamily` | `'Patrick Hand', cursive` | all map text (bundled OFL font, `assets/fonts/`) |
| paper back | `#e6dcc3` + diagonal grain | flap backs (in `template.html` CSS, `.face.back`) |
| desk | dark warm brown gradient | background behind the paper (`#stage` CSS) |
| sea | `#dde6da` fill, `#8fa08e` coast stroke | water areas in map art |

The paper base color and desk are part of `template.html` (SVG/CSS), not the
config — if a project changes them, change them there and keep `style.paper`
in sync (markers/labels use it as the text halo color).

## Non-negotiables

- **Texture is procedural.** Grain/blotches come from `feTurbulence` filters
  with **fixed seeds** — deterministic, crisp at 4K, no binary assets. Do not
  swap in bitmap textures unless the user provides a scanned paper and accepts
  the 4K softness.
- **Creases stay.** The vertical/horizontal crease gradients at the fold lines
  are the signature of the unfold — the map must always look like it was folded.
- **Geography is hand-drawn, stylized, sparse.** Rough coastlines, `^^` peak
  doodles, dotted coastal shading, one river, a compass rose. No photorealism,
  no map tiles, no dense detail — it must read in under a second at vlog speed.
- **Labels**: Patrick Hand, ~46px at 1080p-stage scale, ink fill with a
  `paint-order: stroke` halo in the paper color so they read over any art.

## Stickers

- Source photo should be **≥ 1000 px on the face** — it is displayed ~300 px
  in a 1920×1080 stage, which is ~600 px at 4K output.
- The white die-cut border is generated by `tools/sticker.mjs` (alpha dilation,
  default 26 px). Consistent border width across all stickers in a project.
- Drop shadow is applied by the template with CSS `drop-shadow` — **never bake
  a shadow into the sticker PNG**, it would double up.
- The signature move: pop-in with overshoot (`easeOutBack`), then a fast damped
  left-right wiggle of ±6° over ~3 cycles. Tune via `wiggle.degrees` /
  `wiggle.cycles`; keep it under ±10° or it turns cartoonish.
- Multiple faces: each location takes a `stickers[]` list; use `offsetX/offsetY`
  to fan companions around the point and a small `rotate` (±3–8°) per sticker
  so a group looks hand-placed, not stacked.

## Motion rules

- Frame 0 is always **fully covered by folded paper back** (clean cut from
  clip A), and the last frames are always **fast zoom + white flash** (clean
  cut to clip B). Do not remove either without the user asking.
- Easings: `easeInOut` for paper/camera, `easeOutBack` only for pops, `easeIn`
  for the final zoom and flash. Nothing linear.
- The camera never shows the desk after the unfold — poses are clamped to the
  map (`clampPose`).
