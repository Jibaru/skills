# Me as a skill

## Installation

**PowerShell (Windows):**
```powershell
.\install.ps1
```

**Bash (Git Bash/WSL):**
```bash
./install.sh
```

## Update

**PowerShell:**
```powershell
.\install.ps1 -Update
```

**Bash:**
```bash
./install.sh --update
```

Skills will be installed to `~/.claude/skills/`
